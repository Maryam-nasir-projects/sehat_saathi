# sehat-saathi-project (Karachi Hospital Directory)

Sehat Saathi is a responsive, multilingual hospital directory website designed to help people explore hospital information in Karachi, Pakistan.

## 🌐 Live Website

[Visit Sehat Saathi](https://maryam-nasir-projects.github.io/sehat-saathi-projects/)

## 📌 Project Overview

Finding reliable hospital information can be difficult when people need to explore different healthcare facilities. Sehat Saathi provides a simple, user-friendly directory where visitors can browse hospitals and access their official websites.

This is an independent student project. It is not affiliated with any hospital and does not provide real medical services or hospital bookings.

## ✨ Features

- **Hospital Directory:** Displays information about 16 hospitals in Karachi.
- **Official Hospital Links:** Provides links to hospital websites.
- **Responsive Design:** Supports mobile phones, tablets, and desktop screens.
- **Mobile Navigation:** Includes a menu toggle for smaller screens.
- **Dark Mode:** Allows users to switch between light and dark themes.
- **Appointment Demo:** Includes an appointment request review and simulated token number.
- **Token Countdown:** Displays a simulated waiting-time countdown.
- **Online Consultation Enquiry:** Provides a demonstration consultation form.
- **Smart Contact Form:** Includes input validation and a character counter.
- **Multilingual Support:** Includes a language selector for English, Urdu, Pashto, Punjabi, Balochi, and Sindhi.
- **Accessible Interface:** Uses semantic HTML, form labels, and responsive layouts.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. For translation features, use an internet connection because the language widget relies on an external service.

## 🏥 Hospital Information

The directory includes links to official hospital websites. Visitors should use those websites to verify current services, contact details, appointment procedures, and other information.

## ⚠️ Important Disclaimer

The appointment confirmation, token number, waiting-time countdown, and consultation enquiry are demonstration features only. They do not create real hospital appointments, connect users to doctors, or provide live queue information.

For medical advice, appointments, or emergencies, contact a qualified healthcare provider or the relevant hospital directly.
